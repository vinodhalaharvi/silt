silt media kit

Live

Served by silt-media mjpeg on port 8090.

Recordings

/rec/ — MP4 segments, playable in this browser.

Written by silt-media record, ten seconds each.

Still

snap.jpg — one frame, from silt-media snap.

On the board

silt-media sources          what cameras this board can see
silt-media mjpeg            live view, here on this page
silt-media record           MP4 segments into /var/www/rec
silt-media rtp 192.168.1.5  H.264 to that host, low latency
silt-media snap             one JPEG

WIDTH=640 HEIGHT=480 silt-media mjpeg usb     pick a size and a source

From your laptop

ffplay http://<board>/silt.sdp        the RTP stream
ffplay http://<board>:8090/           the MJPEG stream
vlc    http://<board>/rec/00000.mp4   a recording

No camera attached? Every command takes test as a source and generates a pattern, so the whole chain works before the hardware arrives.
